Questions people actually ask

Do I need a cookie consent banner?

No. Pulsegrid doesn't set cookies or write to local storage, so there's no personal data to ask permission for.

Will it work with my React or Next.js app?

Yes. The tracker hooks into client-side navigation automatically, so route changes are reported without extra code.

Can I share a dashboard with a client?

Yes — publish a read-only link that opens without an account, and choose exactly which panels are visible on it.

Can I export the raw data?

Yes, from the dashboard at any time, or by calling the same API the dashboard itself is built on.
